Universal Keyboard mod that allows you to control various features I wanted better control over.

Right click something to link the keyboard, and place. Configurable wireless range with 100 blocks default. Current support for:

1. CC:Tweaked computer-- once linked you can type on the keyboard without having the terminal open. Useful if you dont want to set up a pocket computer to do that. Once the keyboard is on the ground you can shift + right click to open a menu that lets you preload things to type. You trigger the script with a redstone pulse. I get thats just like an autostart script, but theres reasons you might want it to be external. This will start the computer when it tries to type, that's helpful too.

2. Any CC:Tweaked peripheral-- because so many mods already add compats for this, I am using that for the majority of the features. Currently the GUI is a little rough but you can see the values being returned by peripheral.call, and you can set anything that allows setting values.

3. Those Create "value panels" that can currently only be controlled manually by clicking and holding with a wrench. If theres only a couple things to choose, you do 0, 1, or 2, or whatever. You can now preload numbers in the same way as I described for the computers, so just shift + right click to open the menu, preload numbers to cycle between, and pulse redstone. Pretty intuitive, but I probably will make a full video walkthrough soon


4. Lastly, and also where I will be expanding-- is the Create: Propulsion Simulated thrusters. There is a special GUI for them to make controlling easier. It uses the CC:tweaked peripheral compat to do this, so it's limited to whatever there is currently a public method for. Will be improved later. See image below:
